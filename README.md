# Комьюнити — вёрстка интернет-магазина

Демо-версия сайта магазина техники Apple в Каспийске и Махачкале.
Свёрстано по макету Figma, готовится к натяжке на 1С-Битрикс.

**Демо:** ссылка на GitHub Pages (см. настройки репозитория)

## Что внутри

- 84 страницы: главная, каталог по 8 разделам, 56 карточек товара, корзина,
  оформление заказа, личный кабинет, Trade-In, рассрочка, скидки, сравнение,
  доставка и оплата, о компании, контакты, юридические страницы, 404.
- `css/styles.css` — все стили, `js/` — скрипты (фильтры, корзина, оформление,
  карточка товара, главная).
- `img/`, `fonts/` — изображения и фирменный шрифт Unica77.

## Сборка

Страницы собираются из общих частей и данных — руками их не правят:

```bash
python3 _catalog.py   # листинги каталога и поиск
python3 _product.py   # карточки товара
python3 _build.py     # шапка, футер, модалки, меню ЛК на всех страницах
python3 _maps.py      # ссылки на Яндекс.Карты
python3 _meta.py      # мета-теги, иконка, карточка для соцсетей
python3 _audit.py     # проверка ссылок и кнопок
```

Данные товаров и фильтров лежат в `_catalog.py`, общие блоки — в `_parts_*.html`.
